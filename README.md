# Dependency Graph Visualizer

Интерактивный веб-инструмент для анализа и визуализации графа зависимостей npm-проектов — портфолио-проект, демонстрирующий применение алгоритмов на графах в связке с современным React-стеком.

![demo](./demo.gif)

## Функционал

### Загрузка данных
- Загрузка собственного `package.json` через файловый диалог
- Вставка JSON вручную в текстовое поле
- 3 встроенных демо-графа: экосистема React, Express.js, граф с циклическими зависимостями

### Визуализация
- Интерактивный граф на базе **ReactFlow**: перетаскивание узлов, зум, панорамирование
- Автоматическая иерархическая раскладка через **dagre** (Sugiyama algorithm)
- Клик по узлу подсвечивает его прямые зависимости (зелёный) и зависимые пакеты (оранжевый)
- Экспорт текущего графа в PNG

### Анализ графа
- **Обнаружение циклических зависимостей** — DFS с трёхцветной раскраской (WHITE/GRAY/BLACK), находит все циклы, подсвечивает участвующие узлы красным
- **Боковая панель** при выборе узла: список прямых зависимостей и зависимых пакетов
- **Статистика**: количество узлов, рёбер, наличие циклов

### Архитектура
Логика анализа (`detectCycles`, `analyzeNode`, `getGraphStats`) вынесена в `src/utils/` как чистые функции — полностью независимые от React-компонентов. Подход повторяет архитектуру оригинального CLI-проекта GraphMaker (Python), где алгоритмы были отделены от вывода.

## Стек технологий

| | |
|---|---|
| React 19 | UI и компонентная архитектура |
| TypeScript (strict) | Интерфейсы `GraphNode`, `GraphEdge`, `GraphData` — без `any` |
| ReactFlow 11 | Интерактивный граф с drag & drop |
| dagre | Автоматическая иерархическая раскладка |
| html-to-image | Экспорт графа в PNG |
| Vite | Сборка и dev-сервер |
| Tailwind CSS v4 | Стилизация |
